## 🌟 Sobre el Proyecto

Una aplicación completa y **100% offline** para estudio bíblico profundo, utilizando modelos de lenguaje locales (Ollama) para análisis teológico, generación de sermones, devocionales y mucho más. Ideal para pastores, estudiantes de teología, profesores de escuela bíblica y todos los que deseen profundizar su conocimiento de las Escrituras.

### 🎯 ¿Por qué usar este sistema?

- ✅ **100% Offline**: Tus datos bíblicos nunca salen de tu computadora
- ✅ **Inteligencia Artificial Avanzada**: Análisis teológico profundo usando LLMs locales
- ✅ **7 Personas de Sermón**: Estilos únicos de predicación (Analítico, Narrativo, Profético, etc.)
- ✅ **Multilingüe**: Soporte para Portugués, Inglés, Español y otros idiomas
- ✅ **Historial Completo**: Todos tus análisis, sermones y devocionales guardados automáticamente
- ✅ **Generador de Preguntas**: Crea cuestionarios bíblicos con hasta 50 preguntas
- ✅ **Exportación PDF**: Genera PDFs profesionales de sermones y estudios
- ✅ **Multi-Versión**: Trabaja con NIV, KJV, RV1960, NVI y otras traducciones

## ✨ Características

### 📚 Lectura y Exégesis
- 🔍 Selección interactiva de libros, capítulos y **múltiples versículos** (ej: "1-5, 10, 15-20")
- 🧠 Generación automática de **explicaciones teológicas profundas**
- 📜 Análisis contextual, histórico y lingüístico (Griego/Hebreo)
- 📖 **Historial de Estudios** con búsqueda inteligente y filtros
- 📄 Exportación a PDF con formato profesional

### 🗣️ Generador de Sermones (7 Personas)
Crea sermones en **7 estilos diferentes** de predicación:

- **🔍 Analítico-Esencia** (El Investigador): Psicología espiritual, motivaciones ocultas
- **📚 Expositivo-Teológico** (El Profesor): Contexto histórico, exégesis, doctrina
- **🎬 Narrativo-Inmersivo** (El Narrador): Atmósfera, emoción, tensión dramática
- **💡 Devocional-Práctico** (El Mentor): Vida diaria, consuelo, pasos prácticos
- **✝️ Cristocéntrico-Tipológico** (El Revelador): Jesús en cada texto, tipos y sombras
- **🔥 Profético-Confrontador** (El Atalaya): Arrepentimiento, santidad, urgencia
- **🛡️ Apologético-Filosófico** (El Defensor): Lógica, razón, defensa de la fe

**Recursos:**
- ✅ Personalización por tema, público objetivo y notas del predicador
- ✅ Alcances flexibles: libro específico, múltiples libros, testamento o Biblia completa
- ✅ Selección de múltiples versículos (ej: "Juan 3:1-16, 19, 25-30")
- ✅ Tiempo de espera dinámico (hasta 10 minutos) para sermones complejos
- ✅ Auto-continuación inteligente (hasta 5 continuaciones automáticas)
- ✅ Historial completo con búsqueda y exportación PDF

### 🧘 Devocional y Meditación
- 🙏 Devocionales personalizados por sentimiento/tema (Gratitud, Paz, Fuerza, etc.)
- 💭 Reflexiones profundas sobre pasajes elegidos
- 🌅 Meditaciones para momentos específicos del día
- 📚 Soporte para múltiples libros y versículos
- 🗂️ **Historial de Devocionales** con búsqueda y filtros
- 📄 Exportación a PDF

### 💬 Chat Teológico Inteligente
- ❓ Preguntas y respuestas basadas en versículos específicos
- 📖 Análisis interpretativo y doctrinal profundo
- 🌍 Contexto histórico, cultural y lingüístico
- 📚 Varios alcances: versículo, múltiples libros, testamento o Biblia completa
- 💾 **Historial de Conversaciones** para consultas anteriores
- 📄 Exportación a PDF

### ❓ Generador de Preguntas Bíblicas
- 🎯 Genera de 1 a **50 preguntas** sobre cualquier libro o alcance
- ✅ Modo **Con Respuestas** o **Solo Preguntas** (para cuestionarios)
- 📚 Alcances: libro específico, múltiples libros o Biblia completa
- 🧠 Respuestas cortas y directas (1-2 frases) con lenguaje teológico equilibrado
- 💾 Historial completo con filtros por modo
- 📄 Exportación PDF formateado

### 📥 Importar Datos Bíblicos
- 🌐 Organización por idioma (pt/, en/, es/, etc.)
- 📦 Importación automática de múltiples versiones bíblicas
- ✅ Soporte para NVI, ACF, AA, KJV, NIV, RV1960 y otras
- 🔄 Fusión inteligente con versiones existentes
- 📁 Sistema de carpetas organizado: `Datos_Json/{idioma}/`

## 🚀 Instalación

### Para Usuarios Finales (Recomendado)

👉 **[Descargar Última Versión](https://github.com/rogerirsilva/Sistema-completo-de-estudo-biblico-com-IA-local-Ollama-7-personas-de-serm-o-23-idiomas/releases/latest)**

1. **Descarga el Instalador** y ejecuta el `.exe` descargado.
2. **Instala Ollama** desde [ollama.com](https://ollama.com/) y ejecútalo.
3. **Descarga el modelo de IA** en la terminal: `ollama pull llama3.2:1b`
4. **Abre la aplicación** desde el acceso directo del Escritorio.

### Para Desarrolladores

1. Instala: **Python 3.11+**, **Node.js LTS**, **Rust & Cargo**, **Ollama**
2. `git clone` el repositorio y entra en la carpeta
3. `python -m venv .venv && .venv\Scripts\activate && pip install -r requirements.txt`
4. `cd tauri-launcher && npm install && npm run tauri:dev`
5. Para generar instalador: `tauri_build_installers.bat` (en la carpeta raíz)

👉 **[Guía Detallada de Instalación](INSTALL.es.md)**

## 📁 Estructura del Proyecto

```
Biblia/
├── 📄 bible_data_importer.py          # Importador de datos bíblicos
├── 📄 requirements.txt                # Dependencias Python
├── 📄 bible_data.json                 # Datos bíblicos consolidados
├── 📂 backend/                        # Backend FastAPI
│   ├── main.py                        # Rutas de la API
│   └── services/                      # Servicios (bible, ollama, etc.)
├── 📂 tauri-launcher/                 # Frontend Desktop Tauri
│   ├── src/                           # Código fuente del frontend
│   ├── src-tauri/                     # Configuración Rust/Tauri
│   └── python_app/                    # Backend embebido en el instalador
├── 📂 Dados_Json/                     # Versiones bíblicas por idioma
│   ├── pt/                            # Portugués (NVI, ACF, AA)
│   ├── en/                            # Inglés (KJV, NIV, ESV)
│   └── es/                            # Español (RV1960, RV1995)
├── 📂 chroma_db/                      # Base de datos vectorial
├── 📂 translations/                   # Traducciones de la interfaz
├── 📂 tools/                          # Scripts utilitarios
└── 📂 .venv/                          # Entorno virtual Python
```

## 🔧 Solución de Problemas

### ❌ Ollama no conecta

```bash
# Verificar estado
curl http://localhost:11434/api/version

# Iniciar manualmente
ollama serve

# Windows: verificar si está ejecutándose
tasklist | findstr ollama
```

### ❌ Modelo no encontrado

```bash
# Listar modelos instalados
ollama list

# Descargar modelo recomendado
ollama pull llama3.2:1b

# Probar modelo
ollama run llama3.2:1b "Hola"
```

### ❌ Error al importar versiones

```bash
# Activar entorno virtual
.venv\Scripts\activate

# Reinstalar dependencias
pip install -r requirements.txt --force-reinstall

# Verificar estructura de carpetas
dir Datos_Json\es
```
